## Phase folders

- `01_requirements/` — Kickoff: scope, KPIs, sign-off
- `02_data_source_analysis/` — Discovery: source inventory, dictionary, profiling
- `03_raw_data/` — Ingest: sacred raw copies, one subfolder per source
- `04_data_processing/` — Transform: scripts, cleaned, transformed, QA
- `05_data_model/` — Model: schemas, measures, semantic layer
- `06_dashboard_development/` — Build: wireframes, dev reports, assets, versions
- `07_UAT/` — Test: test cases, bugs, sign-off
- `08_production/` — Deploy: published reports, deployment notes, monitoring
- `09_documentation_governance/` — Govern: lineage, user guide, lessons learned

Tip: zip this folder as a template and unpack at the start of each new project.
